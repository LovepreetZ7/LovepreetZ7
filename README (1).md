# Hi, I'm Lovepreet Singh

I run **Raptuner Distribution Private Limited**, a music distribution and music technology business. I build web tools for our day-to-day work: tracking how a music catalogue performs on YouTube, managing tasks within the team, and automating repetitive content workflows.

## Projects

| Project | What it does | Built with | Repository |
|---|---|---|---|
| [YouTube Catalogue Analytics](https://github.com/LovepreetZ7/YouTube-Catalogue-Analytics) | Records YouTube view counts every hour and shows trends for each video, label and catalogue. Started July 2025, live and in use. | PHP, MySQL, JavaScript, Chart.js, YouTube Data API v3, cron jobs | Showcase |
| [Task Desk](https://github.com/LovepreetZ7/task-desk) | Shared task tracker that replaced a WhatsApp workflow between the business owner and assistant. In use within the business. | PHP, JSON file storage, JavaScript | Full source code |
| [Bulk Transcript Grabber](https://github.com/LovepreetZ7/youtube-bulk-transcript-grabber) | Chrome extension that saves transcripts from many YouTube videos at once as clean TXT files. | JavaScript, Chrome Extensions (Manifest V3) | Full source code |
| [Suno Batch Song Creator](https://github.com/LovepreetZ7/suno-batch-song-creator) | Chrome extension that submits a batch of songs from a JSON or Markdown file to Suno's create page. | JavaScript, Chrome Extensions (Manifest V3) | Showcase |

## Technologies

- **Backend:** PHP, MySQL / MariaDB, JSON file storage, cron jobs
- **Frontend:** HTML, CSS, JavaScript, Chart.js
- **Browser extensions:** Chrome Extensions (Manifest V3)
- **APIs and hosting:** YouTube Data API v3, shared PHP hosting
